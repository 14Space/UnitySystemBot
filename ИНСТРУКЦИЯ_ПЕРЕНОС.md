# Инструкция: автозапуск, перенос на другой ПК и передача другу (viaSaverBot)

Памятка простыми словами. Команды можно копировать, заменяя только то,
что в `<угловых скобках>`. Все команды — из папки `C:\PROJECTS\viaSaverBot`
в терминале PowerShell.

---

## 1. Как бот запускается сейчас

viaSaverBot целиком живёт в Docker и поднимается сам после перезагрузки ПК.
В Docker работают ДВА контейнера:
- `viasaverbot-bot-1` — сам бот (использует видеокарту для расшифровки голосовых);
- `viasaverbot-telegram-bot-api-1` — помощник, который снимает лимит файлов
  с 50 МБ до 2 ГБ.

Терминал держать открытым НЕ нужно. `py -3.12 -m bot.main` вручную больше НЕ запускаем.

Повседневные команды:

| Что хочешь сделать                          | Команда                          |
|---------------------------------------------|----------------------------------|
| Проверить, жив ли бот                        | `docker ps`                      |
| Посмотреть логи бота                         | `docker logs viasaverbot-bot-1`  |
| После правки кода — пересобрать и запустить   | `docker compose up -d --build`   |
| Остановить всё                              | `docker compose stop`            |
| Запустить снова                             | `docker compose up -d`           |

Редактирование кода и пуш в GitHub НЕ изменились. Меняется только команда
«перезапустить после правок» (3-я строка).

---

## 2. Что переносить руками (секреты), а что нет

В GitHub НЕ попадают (и переносятся вручную — флешка/личное облако):
- `.env` — токены, ключи, ID администратора, настройки.
- `bot.db` — база (кэш файлов, пользователи, кто купил Premium).
- `.cache` — сохранённый токен Spotify (не обязателен, подтянется сам).
- `data/instagram_cookies.txt` — куки Instagram, ЕСЛИ ты их используешь.

НЕ нужно переносить:
- Модель распознавания (3 ГБ) — на новом месте Docker скачает её сам один раз.

## 3. Перенос на ТВОЙ второй ПК

ВАЖНО: для быстрой расшифровки голосовых на новом ПК нужна **видеокарта NVIDIA**.
Без неё бот тоже запустится, но расшифровка будет идти на процессоре (медленно).
Большие файлы и скачивание работают без видеокарты.

На НОВОМ ПК один раз установить:
- Docker Desktop (с включённой поддержкой видеокарты — она работает через WSL2,
  обычно включается сама на свежих версиях Windows + драйверах NVIDIA);
- Git.

Затем:

1. Скачать код:
   ```
   git clone <ссылка-на-репозиторий> viaSaverBot
   cd viaSaverBot
   ```
2. Перенести секреты со старого ПК (см. раздел 2): `.env`, `bot.db`,
   при необходимости `data/instagram_cookies.txt`.
3. Запустить:
   ```
   docker compose up -d --build
   ```
4. Проверить, что видеокарта подхватилась:
   ```
   docker logs viasaverbot-bot-1
   ```
   Ищем строку «Модель Whisper загружена.» сразу после «на GPU (cuda)».
   Если вместо этого «перехожу на CPU» — видеокарта не подхватилась
   (это вопрос драйверов/настройки Docker, напиши мне — поправим).
5. На СТАРОМ ПК остановить, чтобы не было двух копий:
   ```
   docker compose down
   ```

## 4. Передача ДРУГУ — закрытая коробка без доступа к коду

Идея: ты собираешь готовый образ (код внутри запечатан) и кладёшь в ПРИВАТНОЕ
хранилище. Друг запускает у себя одной командой, кода не видит.

Помни про две вещи:
- У друга для расшифровки голосовых тоже нужна **видеокарта NVIDIA**.
- Друг, у которого крутится бот, технически имеет доступ к секретам (бот ими
  пользуется на его ПК) — это вопрос доверия. Спрятать получится КОД.

### Шаг 4.1. (ты, один раз) Собрать и залить образ бота

Замени `<логин>` на свой логин Docker Hub (как завести — см. раздел 5).
ВАЖНО: репозиторий на Docker Hub должен быть ПРИВАТНЫМ.

```
docker login
docker build -t <логин>/viasaverbot:latest .
docker push <логин>/viasaverbot:latest
```

### Шаг 4.2. (ты, один раз) Дать другу доступ

В настройках приватного репозитория на Docker Hub добавь логин друга
в «Collaborators». Тогда скачать образ сможет только он.

### Шаг 4.3. (друг) Запустить у себя

Другу нужен Docker Desktop с поддержкой видеокарты. Код и Git ему НЕ нужны.
Ты передаёшь ему ДВА маленьких файла (в них нет твоего кода):

1. Файл `docker-compose.yml`:
   ```yaml
   services:
     telegram-bot-api:
       image: aiogram/telegram-bot-api:latest
       restart: unless-stopped
       environment:
         TELEGRAM_API_ID: ${TELEGRAM_API_ID}
         TELEGRAM_API_HASH: ${TELEGRAM_API_HASH}
       volumes:
         - tg-api-data:/var/lib/telegram-bot-api

     bot:
       image: <логин>/viasaverbot:latest
       restart: unless-stopped
       env_file:
         - .env
       environment:
         TELEGRAM_LOCAL_API_URL: http://telegram-bot-api:8081
       volumes:
         - ./data/downloads:/app/data/downloads
         - ./bot.db:/app/bot.db
         - tg-api-data:/var/lib/telegram-bot-api:ro
         - whisper-cache:/cache
       depends_on:
         - telegram-bot-api
       deploy:
         resources:
           reservations:
             devices:
               - driver: nvidia
                 count: all
                 capabilities: [gpu]

   volumes:
     tg-api-data:
     whisper-cache:
   ```

2. Файл `.env` с заполненными секретами (ты отдаёшь его другу готовым —
   так ему НЕ придётся ничего вводить руками). Это безопаснее, чем «запекать»
   секреты в образ, потому что образ может случайно стать публичным, а файл — нет.

Друг кладёт оба файла в одну папку и выполняет:
```
docker login           # под СВОИМ логином, которому ты дал доступ
docker compose up -d
```

> Оговорка: Docker прячет код «от обычного взгляда». Очень грамотный человек при
> большом желании может вскрыть образ. Для обычного друга код будет невидим.

## 5. Как завести аккаунт Docker Hub (бесплатно)

1. https://hub.docker.com → «Sign Up». Придумай логин, укажи почту, пароль.
2. Подтверди почту по письму.
3. «Create Repository» → имя `viasaverbot` → видимость **Private** → Create.
4. На своём ПК один раз: `docker login` (логин и пароль от Docker Hub).

Бесплатный тариф даёт один приватный репозиторий — этого хватает.
